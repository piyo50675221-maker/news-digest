# 資産管理アプリ（MVP）

個人資産と家計資産（銀行口座・証券口座・年金・暗号資産・クレジットカード利用状況）を、夫婦でアカウントを切り替えながら管理するローカル運用のWebアプリです。

## できること（MVP）

- ユーザーごとのログイン（自分・配偶者の2アカウントを想定）
- 「個人」「家計」の表示切替
  - 個人タブ: 自分だけが閲覧・編集できる
  - 家計タブ: ログインしている全員が閲覧・編集できる
- 口座管理（銀行・証券・年金・暗号資産・クレジットカード）の追加・編集・削除
- 口座残高の手入力、およびCSVファイルからの一括インポート（列マッピング対応、UTF-8/Shift_JIS自動判定）
- 資産ポートフォリオ（資産クラス別の円グラフ、口座別内訳、純資産推移の折れ線グラフ）

次フェーズ（今回のスコープ外）: 支出項目別の家計簿・予算管理、クレジットカードの締め日/支払サイクル管理、相続サポート機能（連絡先・手続きメモ、エンディングノート）。

## 構成

- `backend/`: FastAPI + SQLAlchemy + SQLite
- `frontend/`: React + TypeScript + Vite + Tailwind CSS + Recharts

## セットアップ

### 1. バックエンド

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

初回のみ、自分と配偶者のユーザーを作成します（対話式でパスワードを設定）。

```bash
python scripts/create_user.py self "自分の表示名"
python scripts/create_user.py wife "配偶者の表示名"
```

サーバーを起動します（DBファイルは `backend/data/app.db` に自動作成されます）。

```bash
uvicorn app.main:app --reload
```

### 2. フロントエンド

```bash
cd frontend
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます（`/api` へのリクエストはVite devサーバーが `http://localhost:8000` にプロキシします）。

## CSVインポートについて

マネーフォワードなどの外部アプリとはAPI連携・自動同期は行いません（認証情報を扱うリスクや規約の問題があるため）。口座の「CSV取込」ボタンから、以下の形式のCSVファイルをアップロードしてください。

- ヘッダー行必須。「日付」列と「残高」列（列名は任意、アップロード後に選択可能）
- 日付フォーマット: `YYYY-MM-DD` / `YYYY/MM/DD` / `YYYY.MM.DD`
- 残高は数値（カンマ・円記号は自動で除去されます）
- 文字コードはUTF-8 / Shift_JIS(CP932) を自動判定

マネーフォワードの「資産推移CSV」など機関ごとに列が分かれた横持ち形式の場合は、対象口座の列だけを抜き出して上記の2列（日付・残高）形式に整形してからアップロードしてください。同じ日付のデータを再インポートすると残高は上書き（Upsert）されます。

## テスト

```bash
cd backend
source .venv/bin/activate
pytest
```

権限ロジック（個人口座が他ユーザーから見えないこと、家計口座は両者が編集できること）、ポートフォリオの集計（クレジットカードを負債として純資産から差し引く計算含む）、CSVインポートのパースについてユニットテストがあります。
